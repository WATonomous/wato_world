# INDEX RESOLUTION

# considers only the FIRST index that carries a given package name, which
# breaks here: download.pytorch.org/whl/cu128 mirrors common packages like
# certifi at its own versions, so the default strategy refuses to fall back to
# PyPI for them and the install fails to resolve. unsafe-first-match walks the
# indexes in order and takes the first that has the *requested version* — PyPI
# for ordinary packages, the cu128 index only for the wheels PyPI lacks

#
